Este proyecto es un prototipo de app creado en Android Studio con Kotlin + Jetpack Compose,
la idea principal era crear una aplicacion tipo album donde pudieras almacenar imágenes y videos
con música añadida para poder luego visualizarlos a modo de presentación y compartirlo con tus amigos.
Este proyecto se comenzó con la finalidad de practicar y aprender el desarrollo de apps en Android con -
Kotlin y implementar en la app Firebase para la base de datos, autenticación y crashlytics (Informes de fallos).
Resulto ser bastante complejo y se fue quedando de lado, pero en este prototipo se pueden apreciar conocimientos básicos
aplicados. **IMPORTANTE - EN EL REPOSITORIO HAY UNA CARPETA LLAMADA Moodify_Demo DONDE SE ENCUENTRA UN VIDEO E IMAGEN DONDE
SE DEMUESTRA EL FUNCIONAMIENTO DE ESTA Y LA IMPLEMENTACION DE CRASHLYTICS**
